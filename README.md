# Tacz Attribute

[TaCZ（Timeless and Classics Zero）](https://modrinth.com/mod/timeless-and-classics-zero) の銃の性能を、プレイヤーの **属性（Attribute）** で変えられるようにする Forge MOD です。
装備・ポーション・コマンド・他の MOD などから属性を変えるだけで、ダメージ・連射速度・リロード速度・反動などを調整できます。

## 動作環境

| 項目 | バージョン |
|---|---|
| Minecraft | 1.20.1 |
| Forge | 47.3.0 以降 |
| TaCZ | 1.2.0 以降（1.2.0-hotfix で確認） |

クライアントとサーバーの両方に導入してください。

## 属性一覧

すべての属性 ID は `tacz_attribute:` で始まります。「倍率」の属性は 1.0 が通常の値です。

### ダメージ・弾丸

| 属性 ID | 初期値 | 範囲 | 効果 |
|---|---|---|---|
| `base_damage` | 0 | -1024 〜 1024 | 弾のダメージに加算します（倍率より先に計算）。 |
| `scale_damage` | 1 | 0 〜 1024 | 弾のダメージ倍率です。最終ダメージは `(元のダメージ + base_damage) × scale_damage` です。 |
| `add_headshot` | 0 | -1024 〜 1024 | ヘッドショット倍率に加算します。 |
| `armor_pierce` | 0 | -1 〜 1 | 防御貫通率に加算します（命中時に 0 〜 1 に収まるよう調整）。 |
| `base_knockback` | 0 | 0 〜 1024 | ノックバックの強さに加算します。 |
| `bullet_life_steel` | 0 | 0 〜 1024 | 与えたダメージ × この値だけ、撃った側の体力を回復します。 |
| `bullet_speed` | 1 | 0 〜 100 | 弾速の倍率です。 |
| `bullet_gravity` | 1 | -1024 〜 1024 | 弾にかかる重力の倍率です。 |
| `bullet_friction` | 1 | -1024 〜 1024 | 弾の空気抵抗の倍率です。 |
| `bullet_life` | 1 | 0 〜 1024 | 弾が消えるまでの時間の倍率です。 |

### 射撃

| 属性 ID | 初期値 | 範囲 | 効果 |
|---|---|---|---|
| `auto_rpm` | 1 | 0 〜 100 | フルオート時の連射速度（RPM）の倍率です。 |
| `semi_rpm` | 1 | 0 〜 100 | セミオート時の連射速度の倍率です。バーストの最短間隔にも効きます。 |
| `inaccuracy` | 1 | 0 〜 1024 | 弾の拡散の倍率です。小さいほど正確になります。 |
| `recoil` | 1 | -1024 〜 1024 | カメラ反動全体の倍率です。 |
| `pitch` | 1 | -1024 〜 1024 | 縦方向のカメラ反動の倍率です（`recoil` と掛け合わせ）。 |
| `yaw` | 1 | -1024 〜 1024 | 横方向のカメラ反動の倍率です（`recoil` と掛け合わせ）。 |

空中で撃ったときは、エイム中でも常に「移動時」の拡散になります。

### 弾倉・リロード・移動

| 属性 ID | 初期値 | 範囲 | 効果 |
|---|---|---|---|
| `add_ammo` | 0 | -1024 〜 9999 | マガジンの装弾数に加算します。 |
| `scale_ammo` | 1 | 0 〜 1024 | マガジンの装弾数の倍率です。最終値は `(元の装弾数 + add_ammo) × scale_ammo` です。 |
| `reload` | 1 | 0.05 〜 20 | リロード速度の倍率です。2 なら半分の時間、0.5 なら 2 倍の時間になります。 |
| `gun_weight` | 1 | -1024 〜 1024 | 銃を持ったときの移動速度補正（重量による減速と、銃ごとの移動速度補正）の倍率です。 |

## リロード速度について

`reload` 属性はリロードの経過時間そのものを倍速にします。

- サーバー側の処理（弾が込められるタイミング、リロード完了まで）が倍率どおりに早く／遅くなります。Lua スクリプトでリロードを制御している銃にも効きます。
- 速度はリロード開始時点の値で固定されます。リロード中に属性が変わっても、進行度が飛んだり巻き戻ったりしません。
- 一人称のリロードアニメーション（名前に `reload` を含むもの）も同じ倍率で再生されます。アニメーションに組み込まれた効果音・パーティクルも一緒にずれずに再生されます。
- TaCZ がリロード開始時に鳴らすリロード音（`reload_empty` / `reload_tactical`）も同じ倍率で速く／遅く再生されます。Minecraft の仕様で音の再生速度は 0.5 〜 2 倍が上限のため、その範囲を超える倍率では音だけ追いつかなくなります。

## 使い方の例

```mcfunction
# リロードを 2 倍速にする
/attribute @s tacz_attribute:reload base set 2

# ダメージを 1.5 倍にする
/attribute @s tacz_attribute:scale_damage base set 1.5

# マガジンを +10 発
/attribute @s tacz_attribute:add_ammo base set 10

# 反動を半分にする
/attribute @s tacz_attribute:recoil base set 0.5
```
